# LeetCode Solutions in Python

A curated set of my **LeetCode solutions in Python**, written to sharpen algorithmic thinking and interview readiness while keeping code clean and easy to understand.

This repo is Python-only so I can focus on:
- Writing readable solutions fast
- Using Pythonic patterns appropriately
- Practicing optimal data structure usage

---

## What You'll Find

- Solutions from easy to hard difficulty
- Clean, structured code with practical comments
- Multiple approaches when a problem has tradeoffs (e.g., brute force → optimized)

---

## Topics Covered

You’ll see problems across:
- Arrays / Strings
- Hash Maps / Sets
- Two Pointers / Sliding Window
- Stack / Queue
- Linked Lists
- Trees / Graphs (DFS/BFS)
- Binary Search
- Heap / Priority Queue
- Dynamic Programming
- Greedy
- Backtracking

---

## Structure and Style

- One problem per file
- Naming style usually:
  - `####-problem-name.py` (recommended), or
  - `problem-name.py`
- Solutions aim to include:
  - brief reasoning via comments
  - clean helper functions if needed
  - time and space complexity awareness
